# Personal Assistant (Персональний помічник)
Персональний помічник для керування контактною інформацією та нотатками через консольний інтерфейс (CLI). Проєкт реалізовано мовою Python з використанням об'єктно-орієнтованого програмування (ООП) та зберіганням даних на диску.

---

## 🚀 Основний функціонал

### 📇 Адресна книга (Contacts)
* **Зберігання контактів:** додавання імені, кількох номерів телефонів, email, адреси та дня народження.
* **Валідація даних:**
  * Номер телефону повинен містити чітко **10 цифр**.
  * Email перевіряється за допомогою **регулярних виразів (regex)**.
  * Дата народження приймається у форматі **DD.MM.YYYY**.
* **Пошук та виведення:**
  * Глобальний пошук по всіх полях контакта (ім'я, телефон, email, адреса).
  * Виведення контактів, у яких день народження припадає на найближчі $N$ днів (з автоматичним перенесенням привітання з вихідних на понеділок).
* **Керування:** редагування телефонів/email та видалення контактів.

### 📝 Нотатки та теги (Notes & Tags)
* **Текстові нотатки:** створення, пошук за вмістом та видалення.
* **Теги (Tags):** додавання ключових слів до нотаток.
* **Пошук за тегами:** швидка фільтрація нотаток за відповідним тегом.

### 🧠 Інтелектуальний інтерфейс та надійність
* **Автопідказка команд:** у разі помилки у веденні команди система використовує нечіткий пошук (`difflib`) та пропонує найближчий правильний варіант.
* **Безпека даних:** автоматичне збереження адресної книги та нотаток у файли `.pkl` (папка `data/`) при виході з програми.
* **Обробка помилок:** використання декораторів для перехоплення некоректних аргументів без аварійного завершення програми.

## 📖 Список доступних команд

### Контакти
* **add** — Додати контакт або телефон. Приклад: `add Alex 0671234567`
* **change** — Змінити номер телефону. Приклад: `change Alex 0671234567 0507654321`
* **phone** — Показати телефони контакту. Приклад: `phone Alex`
* **all** — Вивести всі контакти. Приклад: `all`
* **delete** — Видалити контакт. Приклад: `delete Alex`
* **add-birthday** — Додати день народження. Приклад: `add-birthday Alex 25.10.1995`
* **show-birthday** — Показати день народження. Приклад: `show-birthday Alex`
* **birthdays** — Дні народження на N днів. Приклад: `birthdays 14`
* **add-email** — Додати email контакту. Приклад: `add-email Alex alex@test.com`
* **edit-email** — Змінити email контакту. Приклад: `edit-email Alex new@test.com`
* **add-address** — Додати адресу контакту. Приклад: `add-address Alex Kyiv, Khreshchatyk 1`
* **search** — Пошук у контактах за текстом. Приклад: `search Kyiv`

### Нотатки
* **add-note** — Створити нотатку. Приклад: `add-note Купити молоко та хліб`
* **add-tag** — Додати тег до нотатки. Приклад: `add-tag Купити молоко та хліб покупочки`
* **search-notes** — Пошук нотаток за текстом. Приклад: `search-notes молоко`
* **search-by-tag** — Пошук нотаток за тегом. Приклад: `search-by-tag покупочки`
* **all-notes** — Вивести всі нотатки. Приклад: `all-notes`
* **delete-note** — Видалити нотатку за текстом. Приклад: `delete-note Купити молоко та хліб`

### Загальні
* **hello** — Привітання від бота
* **close** або **exit** — Зберегти дані та завершити роботу

├── main.py                # Головний файл запуску (CLI інтерфейс)
